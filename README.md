# QR & Barcode Detection System 🔍

## 🚀 Features
* **Simple GUI:** User-friendly interface with a single-button operation.
* **Auto-Detection:** Supports both QR codes and various Barcode formats.
* **Smart Link Handling:** Automatically recognizes URLs (even those without `http://`) and opens them in the browser.
* **Cross-Format Support:** Works with `.png`, `.jpg`, `.jpeg`, and `.bmp` files.

## 🛠️ Required Libraries
Before running the project, you need to install the following:
